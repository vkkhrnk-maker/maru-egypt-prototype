# MARU — прототип сайта недвижимости в Хургаде

Чёрно-белый кликабельный прототип сайта по продаже недвижимости в Хургаде и на курортах рядом (Сахль-Хашиш, Макади, Сома-Бей, Эль-Гуна) для русскоязычных покупателей. Это макет структуры, без дизайна. Название MARU рабочее.

**Все объекты, цены, курсы валют, имена и контакты в прототипе вымышлены.** Юридические формулировки — заготовки, их должен проверить юрист перед запуском.

## Что внутри

- Шесть экранов: главная, каталог, страница жилого комплекса, объект вторички, «Как купить», карта сайта.
- Версия для десктопа и для телефона. Переключатель «Десктоп / Телефон» — в верхней полосе, на телефоне мобильная версия открывается сама.
- Переключатель валют USD / RUB / EUR, рабочие фильтры каталога, калькулятор рассрочки, квиз.
- Нумерованные заметки на экранах объясняют, зачем нужен каждый блок. Выключаются галочкой «Заметки».

## Файлы

| Путь | Что это |
| --- | --- |
| `prototype/index.html` | Исходник прототипа: один файл на чистом HTML, CSS и JavaScript, без сборки и зависимостей |
| `docs/index.html` | Собранная копия для GitHub Pages (с `<head>`, кодировкой и noindex). Не править руками |
| `scripts/build.py` | Собирает `docs/index.html` из исходника |

## Как обновить сайт

1. Правьте `prototype/index.html`.
2. Выполните `python3 scripts/build.py`.
3. Закоммитьте `prototype/` и `docs/` и отправьте в `main`. GitHub Pages обновится сам.

Локальный просмотр: `python3 -m http.server --directory docs 8000` и откройте http://localhost:8000.
